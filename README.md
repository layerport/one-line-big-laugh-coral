Entry for the [One Line, Big Laugh](https://make.fun/bounty/u-coral-404-one-line-big-laugh-328fb857) bounty on [make.fun](https://make.fun).

The program writes one original funny line (79 characters) to `/output/entry.txt`.
A judge model compares entries pairwise; the funniest lines take the reward.

## The line

> I asked AI to write my wedding vows; it left me at the altar for a newer model.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```

Python 3.13, standard library only, deterministic — every run writes the
same bytes. No network, no secrets, no dependencies.
